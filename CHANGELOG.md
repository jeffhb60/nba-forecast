## [0.1.0] - 2026-11-26

### Added

- Installable Python package with Bronze, Silver, Gold and ML module boundaries.
- Immutable environment-based settings and explicit standard-library logging setup.
- setuptools/pip dependency management and pytest/Ruff configuration.
- Automated configuration, logging and import-side-effect tests.
- Git ignore and line-ending conventions, plus Windows/Linux GitHub Actions CI.
- README, architecture, roadmap, changelog and persistent Claude Code instructions.

No ingestion, database schemas, feature generation or model implementation yet.
